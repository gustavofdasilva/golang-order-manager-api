# Order Management API

A backend API built with Golang for managing odder, with authentication and scalable architecture.

## 🚀 Tech Stack
- Golang
- PostgreSQL
- Docker
- REST APIs

## 📦 Features
- JWT Authentication
- CRUD operations
- Database migrations
- Rate limiting

## ▶️ Running the project

docker-compose up

make migrate-up

make run

## 📌 Endpoints
- POST /auth/register
- POST /auth/login
- GET /tasks

## 🧠 Architecture
Layered architecture (handlers, services, repositories)
